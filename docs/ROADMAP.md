# OpenSTEM Replicate — controlled expansion

## Current v2 features (implemented)

- Curated 20 September 2026 research highlights, verified identifiers, source citations, original educational notes and dedicated publication pages.
- Manual monthly archive workflow with source-controlled month JSON and build-time validation.
- Submissions for editorial consideration with optional PDF attachment routed through FormSubmit after recipient activation.
- AI research idea guidance page with "Coming Soon" status and reusable prompt.
- Discord/community invitation and direct contact email; scholarships and internships point to OpenSTEM Field.
- Three pre-existing deterministic scientific simulation/analysis tools and a documentation readiness checklist.
- Search, discipline filters, saved article buttons (browser-local), copyable references, mobile responsive UI.
- Static SEO build: distinct titles and descriptions, open graph tags, `Article` JSON-LD for **OpenSTEM's own original editorial pages**, canonicals and sitemap from real domain.

## What to add only if there is measured usage

**Phase A — Editorial tooling:** Admin dashboard, multi-step source review, paper correction tracking, contributor roles, trusted source enrichment, spam safeguards, reviewer log. Avoid public uploads without security moderation.

**Phase B — User portfolios:** Real authentication and opt-in researcher profiles, ORCID connection and bibliographic claim review. Do not assume author identity or university affiliation from name matching alone.

**Phase C — AI research assistant:** Backend API integration (OpenAI or Gemini), authenticated quotas, retrieval-grounded DOI citations, explicit novelty uncertainty, privacy for uploaded drafts and AI expenses dashboard. Never expose provider API keys in static JS.

**Phase D — Research matching:** Verified/opt-in faculty and research group registrations; structured collaboration requests, report/block controls, moderator oversight, verified project vacancies. Do not scrape and publish private contacts.

**Phase E — Paper-specific reproduction:** Curated code/data packages, sandboxed execution, reference results, tolerances and provenance. Do not label paper computationally reproduced unless actual independent checks passed.

## Monthly publisher diversity

September's pilot is a **Nature Portfolio-only** starter collection. For a credible global STEM editorial, recruit volunteer academic reviewers and deliberately diversify publishers and research repositories in October and later editions. Assess review effort before committing to exactly 20 every month.
